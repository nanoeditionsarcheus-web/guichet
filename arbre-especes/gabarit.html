Arbre des espèces

Distance génétique standard de Nei (1972) entre lignées de référence, regroupement UPGMA

Données

Téléversez les matrices d'espèces de référence, une par espèce ou lignée (au moins deux). Disposition FLOCK : identifiant, puis 2 colonnes par locus, une par allèle. Formats : .xls, .xlsx, .csv. Le nom du fichier (sans extension) sert de nom d'espèce ; tous les fichiers doivent partager le même panel de locus. Un allèle vide ou égal à 0 rend le génotype manquant à ce locus. À l'ouverture, la page montre un exemple publié (voir le pied de page).

Arbre UPGMA

Chaque nœud réunit les deux groupes les plus proches ; sa position sur l'axe est la moitié de la distance de Nei moyenne entre ces groupes (arbre ultramétrique). Entre parenthèses : le nombre de génotypes de chaque lignée. L'ordre vertical des lignées n'a pas de sens : seuls les regroupements et les hauteurs des nœuds en ont.

Matrice des distances de Nei (D)

Méthode

Fréquences alléliques calculées, locus par locus, sur les génotypes présents. Distance standard de Nei : I = Jxy / √(Jx·Jy), D = −ln I, où Jx, Jy et Jxy sont les moyennes sur les locus de Σpx², Σpy² et Σpxpy (sans correction pour la taille d'échantillon). Un locus sans aucun génotype dans une lignée est exclu pour toutes les lignées. Arbre : UPGMA, moyenne pondérée par le nombre de lignées réunies ; en cas d'égalité, la première paire dans l'ordre des fichiers est réunie.

Validation : sur quatre jeux microsatellites publiés (microbov, nancycats, jaguar, crocrussula), les distances et les arbres de cette page concordent avec PHYLIP 3.697 (gendist, puis neighbor en mode UPGMA) et avec adegenet 2.1.10 (dist.genpop, méthode 1) suivi de hclust (R, méthode « average ») : topologies identiques, écarts limités à l'arrondi de PHYLIP (10⁻⁶ ou moins).
