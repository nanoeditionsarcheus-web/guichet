Reconstitution du génotype d'une femelle

À partir des génotypes de ses juvéniles, locus par locus, par le nombre de compatibilités

Données

Téléversez le fichier des génotypes des juvéniles (tous les nids ensemble). Disposition FLOCK : identifiant, puis 2 colonnes par locus, une par allèle, avec le nom du locus au-dessus de la première colonne. Formats : .xls, .xlsx, .csv. Un allèle vide ou égal à 0 rend le génotype manquant à ce locus. Pour convertir des génotypes à allèles collés (6 chiffres), utilisez l'outil Mise en forme pour FLOCK. À l'ouverture, la page montre un jeu d'exemple (voir le pied de page).

Les génotypes par locus les plus vraisemblables

Pour chaque locus, la page retient le ou les génotypes candidats compatibles avec le plus grand nombre de juvéniles (NC maximal). Si les génotypes sont exacts, le génotype de la femelle est compatible avec tous les juvéniles génotypés : son NC atteint le nombre de juvéniles génotypés. Quand plusieurs candidats sont à égalité, ils sont tous affichés. Un génotype homozygote est encadré : si un homozygote atteint le NC maximal, tous les génotypes qui contiennent son allèle l'atteignent aussi, et l'homozygote est alors le candidat le plus vraisemblable. L'écart est la différence entre le NC maximal et la valeur suivante ; un grand écart indique que le meilleur candidat se détache nettement des autres. La page n'émet aucun verdict : l'interprétation revient à l'usager.

Les génotypes complets les plus vraisemblables

Génotype complet : génotype de la femelle à tous les locus à la fois, un génotype à deux allèles par locus (« ? » pour un locus sans aucun juvénile génotypé). Les génotypes complets sont les combinaisons, sur tous les locus, des génotypes retenus à chaque locus : s'il n'y a qu'un candidat de NC maximal, on le retient ; si un homozygote est parmi eux, on ne retient que l'homozygote ; sinon, on retient tous les candidats à égalité. L'ordre des lignes n'a pas de signification. En vert : les locus où plusieurs génotypes sont retenus.

Rééchantillonnage aléatoire

Pour chaque taille d'échantillon, la page tire au hasard, sans remise, ce nombre de juvéniles parmi ceux du fichier, reconstitue la femelle, et répète le tirage autant de fois que demandé. Elle compte les tirages qui donnent un seul génotype complet, et ceux qui donnent le même génotype que l'échantillon complet. Si le même génotype revient sur une suite de tailles, on peut d'autant plus s'y fier ; la taille à partir de laquelle on le retrouve donne une idée du nombre minimal de juvéniles nécessaire. Les pourcentages varient légèrement d'une exécution à l'autre ; à la taille de l'échantillon complet, ils valent 100 % par construction.

Détail par locus

Cliquez sur la ligne d'un locus (celle qui commence par ▸) pour faire apparaître son détail, et cliquez de nouveau pour le masquer. Tous les génotypes candidats et leur nombre de compatibilités, du plus grand au plus petit. En vert : NC maximal. Sous chaque graphe, les juvéniles non compatibles avec le ou les meilleurs candidats, utiles pour repérer une erreur de génotypage.

Juvéniles non compatibles

Pour chaque juvénile, les locus où il ne partage aucun allèle avec le ou les génotypes de NC maximal. Seuls les juvéniles concernés sont listés.

Méthode

Méthode de Pierre Duchesne ; voir le texte explicatif. Pour chaque locus, les génotypes candidats sont toutes les paires possibles des allèles observés chez les juvéniles génotypés. Un candidat est compatible avec un juvénile s'il partage au moins un allèle avec lui. Le nombre de compatibilités (NC) d'un candidat est le nombre de juvéniles génotypés avec lesquels il est compatible. Les juvéniles sans génotype à un locus ne comptent pas pour ce locus.

Validation : sur six jeux de données fournis par l'auteur (223 juvéniles au total, 11 locus chacun), les nombres de compatibilités de tous les candidats (636) et le nombre de juvéniles génotypés par locus sont identiques à ceux de son programme Maple. Une seule différence, voulue : le nombre d'allèles observés ne compte pas le code des données manquantes.
