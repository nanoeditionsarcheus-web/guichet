Reconstitution du génotype d'une femelle

À partir des génotypes de ses juvéniles, locus par locus, par le nombre de compatibilités

Données

Téléversez le fichier des génotypes des juvéniles (tous les nids ensemble). Disposition FLOCK : identifiant, puis 2 colonnes par locus, une par allèle, avec le nom du locus au-dessus de la première colonne. Formats : .xls, .xlsx, .csv. Un allèle vide ou égal à 0 rend le génotype manquant à ce locus. Pour convertir des génotypes à allèles collés (6 chiffres), utilisez l'outil Mise en forme pour FLOCK. À l'ouverture, la page montre un jeu d'exemple (voir le pied de page).

Génotype reconstitué

Pour chaque locus, la page retient le ou les génotypes candidats compatibles avec le plus grand nombre de juvéniles (NC maximal). Si les génotypes sont exacts, le génotype de la femelle est compatible avec tous les juvéniles typés : son NC atteint le nombre de juvéniles typés. Quand plusieurs candidats sont à égalité, ils sont tous affichés : les juvéniles ne permettent pas de les départager par ce critère. L'écart est la différence entre le NC maximal et la valeur suivante ; un grand écart indique que le meilleur candidat se détache nettement des autres. La page n'émet aucun verdict : l'interprétation revient à l'usager.

Détail par locus

Tous les génotypes candidats et leur nombre de compatibilités, du plus grand au plus petit. En vert : NC maximal. Sous chaque graphe, les juvéniles non compatibles avec le ou les meilleurs candidats, utiles pour repérer une erreur de génotypage.

Juvéniles non compatibles

Pour chaque juvénile, les locus où il ne partage aucun allèle avec le ou les génotypes de NC maximal. Seuls les juvéniles concernés sont listés.

Méthode

Méthode de Pierre Duchesne ; voir le texte explicatif. Pour chaque locus, les génotypes candidats sont toutes les paires possibles des allèles observés chez les juvéniles typés. Un candidat est compatible avec un juvénile s'il partage au moins un allèle avec lui. Le nombre de compatibilités (NC) d'un candidat est le nombre de juvéniles typés avec lesquels il est compatible. Les juvéniles sans génotype à un locus ne comptent pas pour ce locus.

Validation : sur le jeu d'exemple, les nombres de compatibilités de tous les candidats (123, sur 11 locus) et le nombre de juvéniles typés par locus sont identiques à ceux du programme Maple de l'auteur. Une seule différence, voulue : le nombre d'allèles observés ne compte pas le code des données manquantes.
